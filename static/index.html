Lyrics
Auto-fetch lyrics during tagging
When enabled, synced LRC lyrics (with timestamps) are automatically fetched whenever a track is auto-tagged or a candidate is applied. Falls back to plain lyrics if synced are unavailable. A .lrc sidecar file is saved alongside each track.

Sources tried in order:
🎵 LRCLIB — English, Japanese, Korean, Hindi (synced LRC)
🎵 NetEase Cloud Music — Hindi, Japanese, Korean, Chinese (synced LRC)
📄 JioSaavn — Hindi, Punjabi, Tamil, Telugu, Kannada, Marathi
📄 Lyrics.ovh — Multilingual plain fallback
📄 Genius — English, K-pop, Bollywood
You can also fetch lyrics manually per-track using the 🎵 Lyrics button in the library.
Auto-Sync Behaviour
Auto-tag untagged tracks after every playlist sync
When enabled, the ⟳ Untagged auto-tagger runs automatically whenever a scheduled or manual playlist download finishes with at least one new track. Uses the same iTunes → MusicBrainz → AcoustID pipeline as the library button.
